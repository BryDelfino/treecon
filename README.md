# TREECON:
## Description: <br>
A system for managing Falcata tree gall rust <i>(Uromycladium falcatarium)</i>. It has two edges: <br>
- <b>SCOUT</b>: The mobile edge meant for community, field use. It utilizes the built-in camera
for identifying a tree's gall rust severity. It also utilizes the built-in geolocator
to pin the observations on an interactive map where the community can receive vital information
through map operations such as spread interpolation and forecasting; possible through data from 
both the community and the experts.
- <b>COMMANDER</b>: The web dashboard meant for experts of the field. Experts have 
the option to upload their observations, verify observations made by the SCOUT client, 
and receive vital information from the interactive map.
